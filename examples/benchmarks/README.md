# Benchmark scripts (`examples/benchmarks/`)

Library comparison and smoke benchmarks for **torchregress** itself.

NeurIPS SAGE/SPT reproduction scripts and paper artifacts:
[torchregress-research](https://github.com/sfabbro/torchregress-research).
External-software parity harness:
[torchregress-harness](https://github.com/astroai/torchregress-harness).

## Conventions

- Run from repo root with `uv run python examples/benchmarks/<script>.py …` so imports resolve predictably.
- Prefer **repository-relative** paths in docs and shell history (not machine-specific absolute paths).
