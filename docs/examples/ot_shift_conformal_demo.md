# OT shift conformal demo

This script exercises the experimental test-time helpers:

- `torchregress.test_time.OptimalTransportCoverageGap`
- `torchregress.test_time.OTShiftReweighter`
- `torchregress.test_time.WeightedSplitConformalAdapter`

## Run

```bash
uv run python examples/ot_shift_conformal_demo.py --seed 0
```
