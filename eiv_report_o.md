# Scalable Errors-in-Variables Methods for Deep Regression

## Executive summary

Errors-in-variables (EIV) problems arise when the *inputs* to a regression model (covariates) and/or the *targets* (labels) are measured with error, so training on the observed values induces bias (classically: attenuation/dilution bias) and/or miscalibrated uncertainty unless the noise is explicitly modelled. citeturn18view0turn15view1turn34view0

Across the post‑deep‑learning literature (through March 2026), the EIV methods that most clearly (a) apply to neural regression settings and (b) **explicitly claim or demonstrate scalability** cluster into five scalable patterns: (i) amortized latent‑variable Bayesian EIV using variational inference (VAE/IWAE-style) for large \(n\), citeturn15view1turn39view0 (ii) variational Bayesian deep regression with explicit latent “true inputs” and Monte‑Carlo (MC) approximations/MC dropout, citeturn18view0turn19view3 (iii) **learned input posteriors** (notably diffusion models) to make EIV usable for modern deep nets without hand‑specifying an input posterior, citeturn25view0turn28view0turn30view0 (iv) direct optimisation over *per‑example latent inputs* alongside network parameters (a modern “Deming regression” generalisation), citeturn34view0turn35view0 and (v) instrumental‑variable (IV) deep learning pipelines that scale to large observational datasets and can mitigate endogeneity/measurement‑error-like failures when valid instruments exist. citeturn36view2turn36view3turn38view0

The most end-to-end “deep‑learning-native” scalable EIV approach with mature, official code and strong empirical results is the diffusion‑posterior EIV framework (classification demonstrated; conceptually applicable to regression when a denoising posterior is learned). citeturn28view0turn29view0turn30view0  For pure regression with explicit input uncertainties, LatentNN is the clearest modern “latent‑input” correction, but it introduces an \(O(Nd)\) latent‑state memory footprint that can dominate at very large \(N\). citeturn35view0turn33search1

## Scope and inclusion criteria

This review targets methods that satisfy all of the following constraints:

The method addresses an EIV structure where at least one of \((X, Y)\) is noisy relative to an unobserved “true” variable (e.g., \(W=X+U\), or \(x=\zeta+\varepsilon_x\)), and the method is designed to correct bias and/or properly propagate uncertainty under that structure. citeturn15view1turn18view0turn34view0

The method is applicable to deep regression (continuous outcomes), either directly demonstrated on regression or straightforwardly extensible (e.g., by replacing a categorical likelihood with a Gaussian/NLL regression likelihood while keeping the EIV machinery). citeturn18view0turn15view1turn35view0

The method **explicitly claims or demonstrates scalability** to large neural networks and/or large datasets (e.g., minibatch SGD compatibility, amortised inference, evidence on very large \(n\), or explicit “scalable” positioning plus experiments at meaningful scale). citeturn15view1turn36view2turn25view0turn14view0turn18view0

Because “EIV” is used inconsistently across fields, I include (and label) two partially overlapping families: (a) classical measurement-error EIV (explicit noisy covariates/labels), and (b) modern IV-style deep causal regression approaches that correct for endogeneity and can act as practical “EIV-like” bias correctors when measurement error induces correlation between predictors and residuals and a valid instrument exists. citeturn15view1turn36view2turn38view0turn39view0

## Method taxonomy

```mermaid
flowchart TD
  A[EIV in deep regression] --> B[Latent-variable EIV (Bayesian/VI)]
  A --> C[Latent-variable EIV (direct optimisation)]
  A --> D[Learned input posterior (denoising / diffusion)]
  A --> E[Instrumental variables (deep IV)]
  A --> F[Operator learning EIV (function-to-function)]
  A --> G[Inference-time input uncertainty propagation]

  B --> B1[Amortized inference (VAE/IWAE)]
  B --> B2[MC dropout variational BNN + latent inputs]

  C --> C1[Per-example latent inputs as parameters]

  D --> D1[Diffusion posterior p(zeta|x)]
  D --> D2[Other learned posteriors (denoisers / flows)]

  E --> E1[Two-stage density + outcome nets]
  E --> E2[Two-stage least squares with learned features]

  F --> F1[DeepONet / operator nets with EIV loss]

  G --> G1[GMM Split&Merge propagation]
```

## Discussion

### What is genuinely “SOTA” for scalable EIV in deep regression

The empirical frontier for **deep** EIV has moved from (a) “treat the observed \(x\) as truth and use robust losses” toward (b) **explicit modelling of the latent true input** and integration over \(p(\zeta\mid x)\), because the latter is what prevents systematic bias when the objective is to learn the underlying function of the true covariate. citeturn18view0turn34view0

Within that shift, the main bottleneck has been the practical specification of an input posterior \(p(\zeta\mid x)\) that is both *good enough* and *computationally manageable* for high-dimensional inputs. The diffusion-based approach is notable because it treats learning \(p(\zeta\mid x)\) as a first-class problem and shows measurable performance and calibration gains under strong noise on standard deep-learning datasets, with official code and pretrained artefacts. citeturn25view0turn28view0turn30view0

### Complexity and scaling trade-offs that matter in practice

A key dividing line is whether the method is **amortised** or **non-amortised** in latent variables:

NNME and the VF framework use amortised inference (an encoder/inference net produces the approximate posterior parameters), so memory stays roughly \(O(P)\) rather than \(O(Nd)\). This can be the decisive advantage for very large \(N\). citeturn15view1turn39view0

LatentNN is non-amortised: it explicitly optimises \(x_{\text{latent},i}\) for each sample, which adds a persistent latent state scaling as \(O(Nd)\). This is often acceptable in scientific regression regimes (moderate \(N\), carefully modelled uncertainties), but it is a real constraint at web-scale. citeturn35view0turn35view1

A second dividing line is whether the method *learns* a complex input posterior (diffusion EIV) or assumes/derives a simpler posterior (Gaussian latent input in Martin & Elster). The former can unlock accuracy gains in high-dimensional settings but introduces the overhead of training and sampling from a generative model; the latter is lighter-weight but depends on how adequate the Gaussian/noise assumptions are for the actual sensor/data corruption. citeturn26view2turn18view0turn28view2

### Recommended use-cases by data regime

If you have large \(N\), moderate-to-high dimensional covariates, and can specify or estimate the measurement error distribution, amortised VI EIV (NNME-like) is the most natural scalable “statistics-meets-deep-learning” option. citeturn15view1turn17view0

If the dominant need is *calibrated predictive uncertainty under input uncertainty* (and you can accept similar RMSE), the MC-dropout EIV approach in deep regression provides a relatively simple extension on top of standard Bayesian deep-learning tooling. citeturn20view2turn20view1turn19view3

If your inputs are high-dimensional (images, complex sensors) and the corruption process is nontrivial, learned-posteriors (diffusion EIV) currently provide the clearest path to large-model usability and improved predictive performance under input noise, with an “official implementation + pretrained assets” maturity level that is still rare in EIV work. citeturn28view0turn30view0turn29view0

If your domain has **credible per-feature measurement uncertainties** and you care about correcting attenuation bias in regression coefficients/functions (common in scientific inference), LatentNN’s per-sample latent input optimisation is direct and transparent, but you must plan for the \(O(Nd)\) latent-state footprint. citeturn35view0turn33search0

If your “EIV-like” bias is better characterised as endogeneity and you can obtain valid instruments, deep IV approaches demonstrate some of the strongest *dataset-scale* evidence (including tens of millions of observations), but correctness hinges on instrument validity and the causal identification structure rather than on a parametric measurement noise model. citeturn36view3turn36view2turn15view1

Finally, if you cannot retrain the model but must quantify output uncertainty given uncertain test inputs, distribution-propagation methods (Gaussian-mixture Split&Merge) are a pragmatic alternative to MC sampling with claimed accuracy and code availability, albeit not a training-time bias correction. citeturn14view0
