## 2025-04-23 - [Optimize Concordance Index Memory and Speed by Early Indexing]
**Learning:** In survival analysis/censored regression, `concordance_index` calculations usually rely on $O(N^2)$ cross-comparisons between all pairs of samples. In this codebase, the PyTorch implementation initially did `y.unsqueeze(1) < y.unsqueeze(0)` resulting in an $N \times N$ boolean matrix. However, the reference point for any valid pair *must* be an observed sample (`censoring == 0`). So we don't need the full $N \times N$ matrix.
**Action:** Filter the tensors down to only observed elements *before* performing the $O(N^2)$ broadcasting step. For example, doing `y_obs.unsqueeze(1) < y.unsqueeze(0)` drops the output shape to $N_{obs} \times N$. With 50% censoring, this cuts the memory footprint by 50% and yielded a >2x speedup on typical benchmark array sizes (e.g., $N=10000$ drops from 0.610s to 0.284s).
