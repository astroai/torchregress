## 2025-02-23 - Fast Conformal Interval Construction
**Learning:** In PyTorch, allocating explicit coordinate grids (e.g., `torch.arange()`) and running global `torch.where()` masks just to find the start and end of contiguous boolean blocks is extremely slow and memory-intensive, especially inside tight test-time inference loops.
**Action:** When finding the first and last `True` indices in a 1D or batched 2D boolean mask, use `.int().argmax(dim=-1)` for the first index, and `.flip(dims=[-1]).int().argmax(dim=-1)` for the last index (subtracting from the total size). This avoids explicit coordinate tensor creation and executes entirely in fast native reductions. Additionally, prefer using native Python scalars (like `float("inf")`) directly in `torch.where` over wrapping them in `torch.tensor(INF, device=...)` when filling bounding values, combined with `torch.amin`/`torch.amax(..., keepdim=True)`.
