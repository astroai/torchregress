## 2025-03-03 - [Remove test backdoor allowing file scheme in URL validation]
**Vulnerability:** The `validate_url` function in `torchregress/utils/security.py` conditionally allowed the `file` scheme if the `TORCHREGRESS_SECURITY_ALLOW_FILE_URL` environment variable was set to "1". This was intended for testing but introduces an SSRF / Local File Inclusion vulnerability if the variable is accidentally or maliciously set in production.
**Learning:** Security controls should not be bypassed using environment variables, even for testing purposes, as they can bleed into production environments or be exploited via secondary vulnerabilities that allow environment variable manipulation.
**Prevention:** Avoid inserting backdoor test logic into security validation functions. The validation function should enforce security requirements strictly. Tests should pass explicitly allowed schemes as arguments if they need to test non-default behavior, or tests should mock the interactions entirely.
