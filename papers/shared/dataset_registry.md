# NeurIPS Dataset Registry

This file tracks the public datasets and benchmark assets referenced across the
`neurips` branch papers so SPT-Reg and SAGE-Reg can share one source table
without merging their experiment sections.

## Public datasets

| Dataset | Used by | Role | Canonical source |
| --- | --- | --- | --- |
| Diabetes (`sklearn.datasets.load_diabetes`) | SPT-Reg | Small real-data regression shift benchmark | [scikit-learn dataset docs](https://scikit-learn.org/1.1/modules/generated/sklearn.datasets.load_diabetes.html) |
| YearPredictionMSD | SPT-Reg, SAGE-Reg | Large real-data regression shift benchmark for SPT-Reg; large semi-supervised regression benchmark for SAGE-Reg | [UCI Year Prediction MSD](https://archive.ics.uci.edu/dataset/203/yearpredictionmsd) |
| HIGGS | SAGE-Reg | Large-scale OOD / systematic-shift benchmark when local tabular extract is provided | [UCI HIGGS](https://archive.ics.uci.edu/ml/datasets/HIGGS) |

## Branch-local benchmark assets

| Asset | Used by | Role | Notes |
| --- | --- | --- | --- |
| Factorized synthetic shift generator | SPT-Reg | Controlled prior / subspace / variance shift study | Generated by `examples/spt_reg_synthetic_comparison.py`; no external source link needed. |
| Higgs-like proxy generator | SAGE-Reg | Offline smoke fallback for OOD behavior | Used only when no local HIGGS table is supplied. Keep this separate from the public HIGGS citation. |

## Usage guidance

- Cite this registry from each paper's reproducibility note instead of duplicating dataset-source text.
- Keep experiment methodology separate by paper even when a dataset appears in both.
- Prefer canonical dataset landing pages over transient download mirrors.
