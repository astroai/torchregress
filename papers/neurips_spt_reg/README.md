# Shift-Factored Predictive Transport for Probabilistic Regression

This workspace holds the NeurIPS manuscript and artifact map for the SPT-Reg
project on the current research branch.

## Layout

- `main.tex`: single-file manuscript source
- `refs.bib`: bibliography
- `reproducibility.md`: map from tables/figures to generated artifacts

## Working Rules

- Keep `main.tex` as the only build path for the manuscript.
- Keep paper claims tied to generated artifacts under `reports/neurips_spt_reg/`.
- Update the artifact map whenever a figure, table, or benchmark summary changes.
- Keep SPT-Reg paper files separate from SAGE-Reg paper files on this branch.
